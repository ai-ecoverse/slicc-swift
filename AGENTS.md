# slicc-swift

SLICC's local proxy for macOS/iOS: SwiftPM library `SliccSwift` (raw `/api/fetch-proxy`, host folders `/api/hostfs*`, the `<port>.kernel.localhost` tunnel, and the proxy-key, origin, CORS and PNA gate) and the `slicc-swift` launcher. It must match slicc-node's protocol exactly; README documents it. Code comes from SLICC's `packages/swift-server` at `origin/main` (never edit that repo); hostfs, the kernel tunnel and the stored key mirror slicc-node. Lint with `npm run lint` (`slicc-lint-comments`, `slicc-no-unit-tests`, `slicc-agents-md`, `swift format`). No comments in any file (the `swift-tools-version` line is required). Agent guidance lives only in this AGENTS.md (≤1000 characters). Do not add CLAUDE.md. `Tests/SliccSwiftTests` are committed integration tests over real loopback sockets; extra unit tests stay in gitignored `Tests/Unit/`. Releases are GitHub tags only via semantic-release; no npm. No signing or notarization yet.

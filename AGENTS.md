# slicc-swift

Empty Swift package for SLICC's macOS/iOS local proxy. SwiftPM library `SliccSwift`. Lint with `slicc-lint-comments`, `slicc-no-unit-tests`, `slicc-agents-md`, and `swift format`. No comments in any file (the `swift-tools-version` line is required). Agent guidance lives only in this AGENTS.md (≤1000 characters). Do not add CLAUDE.md. Extra unit tests stay in gitignored `Tests/Unit/`. Releases are GitHub tags only via semantic-release; no npm.

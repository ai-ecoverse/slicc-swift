# slicc-swift

Empty Swift package for SLICC's local proxy on macOS and iOS. Migrate from SLICC's `packages/swift-server` and later the other `swift-*` packages.

```swift
import SliccSwift
```

`npm run lint` runs `slicc-lint` and `swift format lint`. CI builds and tests on a macOS runner. Releases are GitHub tags and release notes only.
